# 🛡️ Roadmap Cybersécurité — enrichie

Base de connaissances en cybersécurité construite à partir de la [roadmap officielle roadmap.sh](https://roadmap.sh/cyber-security), **enrichie** (définitions, fonctionnement, intérêt, défenses, commandes) pour servir de support de révision et de « second cerveau » Obsidian.

## 📖 Contenu

👉 **[Cybersecurite-Roadmap.md](./Cybersecurite-Roadmap.md)** — le document complet.

Il couvre 12 domaines :

1. Compétences IT fondamentales
2. Systèmes d'exploitation
3. Réseau (OSI, protocoles, ports, adressage)
4. Compétences & connaissances en sécurité
5. Cryptographie
6. Types d'attaques
7. Cloud
8. Programmation & scripting
9. Frameworks, normes & conformité
10. Outils (par usage)
11. Certifications
12. CTF & plateformes d'entraînement

## ✨ Format

- **Compatible GitHub *et* Obsidian** : frontmatter YAML, callouts `> [!NOTE/TIP/WARNING]`, sommaire ancré, tableaux, blocs de code.
- **Légende de criticité** : 🟢 fondamental · 🟡 intermédiaire · 🔴 avancé.
- Pensé comme un **MOC** (*Map of Content*) : point d'entrée unique, à éclater en notes atomiques reliées par `[[wikilinks]]` dans Obsidian si besoin.
