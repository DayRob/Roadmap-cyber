# DESIGN BRIEF — Roadmap Cybersécurité enrichie

> Ce dépôt est une **base de connaissances**, pas une application : les rubriques techniques (flux, schéma, design) décrivent ici la structure du contenu, son parcours de lecture et ses conventions de rédaction.

## 1. Ton

Pédagogique, direct, orienté pratique : chaque notion répond à « qu'est-ce que c'est, comment ça marche, pourquoi c'est important, comment s'en protéger ».

## 2. Hiérarchie visuelle

| Niveau | Rendu |
|---|---|
| Titre du document | `#` + emoji 🛡️ |
| Domaine | `## N. <emoji> Titre` (12 domaines + « Aller plus loin ») |
| Sous-partie | `### Titre <pastille>` |
| Séparation | `---` entre domaines |

## 3. Code couleur de criticité

| Pastille | Sens |
|---|---|
| 🟢 | Fondamental |
| 🟡 | Intermédiaire |
| 🔴 | Avancé |

## 4. Callouts

| Callout | Usage |
|---|---|
| `> [!NOTE]` | Contexte, source |
| `> [!TIP]` | Astuce, méthode |
| `> [!WARNING]` | Piège courant |
| `> [!IMPORTANT]` | À retenir absolument |

## 5. Règles de rédaction

- **Gras** pour le terme clé à sa première apparition.
- *Italique* pour les termes anglais (*memory dump*, *juice jacking*).
- Tableaux dès qu'il y a plus de trois éléments comparables.
- Une idée par puce ; phrases courtes.
